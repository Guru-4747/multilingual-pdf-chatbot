# Multilingual AI PDF Chatbot

An AI-powered PDF question answering system using RAG.

## Features

- Large PDF support
- PDF question answering
- RAG architecture
- FAISS vector search
- Multilingual embeddings
- English
- Tamil
- Kannada
- Hindi
- Telugu
- Malayalam
- PDF summaries
- MCQ generation
- Page references

## Technologies

- Python
- Streamlit
- PyPDF
- Sentence Transformers
- FAISS
- Gemini API

## Architecture

PDF → Text Extraction → Chunking → Embeddings → FAISS → Retrieval → Gemini → Answer
